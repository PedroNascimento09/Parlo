Parlo 0.2.6 is a correctness release. The download is now checked before it installs, and the repository stops describing a build that does not exist. Nothing in the engine changed, so 0.2.5 and 0.2.6 dictate and translate the same way; what moved is trust in the file you download and in the sentences that describe it.

## Highlights

- The one-line installers read `SHA256SUMS.txt` from the release, compare the archive they just downloaded and refuse it before unpacking when the hash does not match.
- `docs/LANGUAGES.md` lists only the pairs the catalog ships and marks the directions that run through English.
- The README's recogniser download is the **640 MB** measured on disk; the invented 800 MB figure is gone.
- CI is green on Windows, macOS and Linux again: the smoke step reads the exit code `parlo doctor` documents instead of demanding success, and the benchmark check compares a state only when the local run measured one.
- The repository root lost nineteen screenshots and a stale `sbom.cdx.json`; the README shows one real capture of the bar instead.

## Measured

- Tests: **589** pass with `cargo test --workspace`, 0 failed, `cargo clippy --all-targets -- -D warnings` and `cargo fmt --all --check` clean. Machine: Windows 11, AMD Ryzen 5 3600, 16 GB, no GPU.
- Speech to translated text with Parakeet TDT 0.6B v3 int8 and OPUS-MT en→es on four CPU threads, 1.80 s of English audio: **663 ms**, returned as `Llama al dentista el jueves.` by `POST /dictate`. The Spanish pack was installed by hand, because the app does not offer it yet.
- Recognition and translation are otherwise unchanged from 0.2.5.

## Install

Download `Parlo-Setup.exe` from this release and run it. It installs for the current user, asks for no administrator, and replaces a running copy in place; once this release is live the app offers it from its own update screen.

Windows will show *Windows protected your PC*. The installer is still not code signed, because there is no certificate behind the project yet: check that the file came from this release page, then choose **More info** and **Run anyway**.

## Known limitations

- Spanish is not offered by the app: the pair lives in the model layout and is absent from the catalog, so the demonstration in the README used a pack installed by hand.
- The packaging manifests in this tag still carry the 0.2.5 checksums, because the new archives did not exist when the tag was cut; they are updated on `main` once the build finishes.
- The installer is unsigned, and the window runs on Windows only. macOS and Linux are compiled and tested by CI, but the window has not been opened there.
- No external user has run this build.
