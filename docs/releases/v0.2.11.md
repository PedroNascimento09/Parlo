v0.2.11 makes Parlo start with the computer and repairs the release pipeline that left the previous three releases without a downloadable file.

## Highlights

- **Start at login** is a check item in the tray and `parlo autostart on|off|status` in a terminal. It registers the Parlo window, which starts hidden, so the dictation shortcut answers within a minute of signing in instead of waiting for Parlo to be opened by hand.
- `parlo doctor` now reports whether that entry exists and which program it starts.
- The licence notices and the licence index were stale, and the release workflow regenerates them and refuses to continue when the committed copy differs. Every release since v0.2.8 stopped there and published no assets; the documents are current again.
- The release workflow attaches the Windows installer from the Windows job only, and a new final job fails the run when an expected asset is missing or the release is still a draft. A tag can no longer go live with nothing to download.

## Measured

No recognition, translation or voice path changed in this release, so the recorded numbers stand: **375.0 ms** from the end of the audio to text on the fixed 5.00 s speech clip, silence trimming on, median of five runs, Windows 11, 12-core CPU, no GPU, Parakeet TDT 0.6B v3 int8 on four threads; and **2 ms** from key release to text when the stream closed the sentence on silence, measured on the 2.8 s clip through the app's own server, Polish off.

The new command was timed once on the reference machine, Windows 11, from a debug build: `parlo autostart on` wrote the registry value in **0.103 s**, and `parlo autostart status` reported it correctly before and after `off`. It adds no work to dictation, which reads one registry value at start.

## Install

```powershell
irm https://github.com/PedroNascimento09/Parlo/raw/main/scripts/install.ps1|iex
```

Or download `Parlo-Setup.exe` from this release. Then open Parlo, turn on **Start at login** in the tray, and press `Ctrl+Alt+D` to dictate.

## Known limitations

- The build is unsigned, so Windows may show **Windows protected your PC** once. The release carries `SHA256SUMS.txt` and a build provenance record.
- The login entry registers the program that ran the command. Run `parlo autostart on` from an installed copy, not from a build folder, or the entry will point at that folder.
- The global shortcut exists on Windows only, and macOS and Linux are compiled and tested by CI without the window being opened there.
- Portuguese and English remain the only pairs that ship as measured; the others are marked experimental.
