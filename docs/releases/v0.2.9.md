Parlo 0.2.9 adds a guided first-run onboarding to the island and completes the interface in 21 languages. The app now walks a new user through the microphone check, the shortcut, and a first dictated sentence before handing over the controls, and every interface string is available in every supported language with no fallback to English.

**Highlights**

- Guided first-run onboarding: a Gate walks a new user through a live microphone check, a working shortcut test, and a first dictated sentence that is written out and copied, so a sentence lands in the clipboard before the guide ends.
- Progress is kept in the browser, can be skipped entirely, and the guide can be replayed from Settings at any time. The step counter reads "Step N of M" dynamically as the gate advances.
- The interface is now complete in 21 languages: English, Portuguese, Spanish, French, German, Italian, Dutch, Polish, Russian, Swedish, Danish, Finnish, Norwegian Bokmal, Czech, Romanian, Turkish, Ukrainian, Japanese, Korean, Chinese (Simplified) and Arabic, each with 1366 of 1366 interface strings. No screen falls back to English any more.
- The onboarding strings were translated into the remaining 19 languages with the tone the app already used in each one; the code and the voice packs are untouched by this release.

**Measured**

- 636 Rust tests and 42 web tests pass with 0 failures (`cargo test --workspace`, the island harness), `cargo clippy --workspace --all-targets -- -D warnings` is clean, `cargo fmt --check` passes, `check-languages.mjs` exits 0, and the engine suite reports 45 tests OK under `unittest` in `engines/cascade`.
- Interface coverage was verified by script against EN: all 21 locales carry exactly 1366 keys at 0.2.9, with zero missing, zero extra and zero empty strings.

**Install**

Windows: download `Parlo-Setup.exe` from the v0.2.9 release, or run `winget install Parlo`. Mac and Linux: download the matching `parlo-macos-aarch64.tar.gz` or `parlo-linux-x86_64.tar.gz` archive, extract it, and run `parlo app`. Both carry `SHA256SUMS.txt` and a build provenance record.

Parlo checks the latest release when the app starts and offers the update with these notes beside it. Nothing is installed without a click.

**Known limitations**

- This release adds interface languages only. The speech languages are unchanged; a new speech language still needs its own measured run before it is claimed per `docs/LANGUAGES.md`.
- The package manifests in this tag carry the previous checksums for the archives; they are updated on main once the build finishes.
