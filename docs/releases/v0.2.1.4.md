Parlo 0.2.1.4 says what it holds. Every row in the Models panel now carries the quality number measured for it, or says that no number was measured, and every row says whether the model sits in memory or only on disk. A model that is loaded used to read exactly like one that is downloaded and idle.

## Highlights

- Every model row carries a measured number or a sentence saying there is none. Nothing is left blank.
- The recogniser reads 0.24 word error on 20 European Portuguese sentences, Windows 11, 4 threads.
- Each translation pair reads its own gate result, on numbers, clocks, negations and names.
- The list shows `In memory` for a model the engine holds and `On disk` for one that is downloaded and idle.
- The engine answers a new `loaded` op over the sidecar protocol, so the list reports what is really in memory instead of guessing from files.
- A translation pair reads as loaded only for the direction the engine is set to, because the engine holds one direction at a time.
- `In use` is not shown. The local server answers one request at a time, so no page can read the list while a model is working, and the app does not pretend otherwise.

## Measured

- Tests: **123** in `parlo-cli` and **79** in `parlo-core`, with `clippy -D warnings`, `cargo fmt --check` and `node --check` clean.
- Word error rate: **0.24** on 20 European Portuguese sentences, Parakeet TDT 0.6B v3 int8, Windows 11, 4 threads.
- Translation gate on this project's 100 sentences, 50 in each direction: pt to en **1.000** on numbers, clocks and negations, **0.980** on names; en to pt **1.000** on numbers and negations, **0.980** on clocks and names.
- Smoke run with the real models on disk: `/models` answered `parakeet` loaded, `voice-pt` loaded, `voice-en` loaded, `mt-pt-en` loaded, `mt-en-pt` installed.

## Install

Download `Parlo-Setup.exe` from this release and run it. From 0.2.1.2 onward the update arrives inside the app with these notes beside the button; on 0.2.1 or 0.2.1.1 run the installer once, because the page in those versions cannot start an update.

## Known limitations

- The list shows no memory use and no speed per model. Both are measured elsewhere, neither is shown here.
- `In use` does not exist, for the reason above: one request at a time on a local server.
- The voices carry no quality number, because none was measured. Read aloud is a neutral voice, and no Portuguese voice from Portugal has been judged by listeners.
- Models already on disk from 0.2.1.2 or earlier keep the Brazilian voice until the European one is downloaded and the old one removed.
- The installer is not signed, and macOS and Linux are not supported.
