v0.2.12 makes the first sentence arrive after 142 MB instead of 671 MB, and makes the update button replace the whole program instead of one file inside it.

## Highlights

- **The small model comes first.** On a machine with no dictation model, the first-run button now downloads Whisper base, switches the recogniser to it as soon as it lands, and keeps Parakeet downloading in the background. When Parakeet arrives Parlo switches back to it. Translation and voices stay optional.
- **The update button replaces every program** the release carries: `parlo`, `parlo-app`, the Python and Rust engines and `WebView2Loader.dll`. It swaps them one second after the running process exits, keeps the previous copy beside each file as `.old`, and starts the program that was running, so a window update no longer leaves the old window and the old engine in place.
- **The updater works on macOS and Linux.** It writes a shell script that waits for the process, swaps the files and starts Parlo again. Before this release the button only worked on Windows.
- **`--only` means only that model.** Downloading Whisper no longer pulls the Portuguese and English voices first, and that 121 MB is skipped for every single-model download.

## Measured

Whisper base downloaded **142 MB in 13 s** from the Hugging Face CDN on the reference machine, Windows 11, on this connection, with `setup_models.py --only whisper` and an empty model folder. Before the fix the same command also fetched the two default voices, **121 MB** more. The download is the same one the first-run button starts; the time to the first spoken sentence in the window was not measured in this session, and no recognition, translation or voice number changed, so the recorded figures stand: **375.0 ms** on the fixed 5.00 s clip and **2 ms** from key release when the stream closed the sentence on silence.

## Install

```powershell
irm https://github.com/PedroNascimento09/Parlo/raw/main/scripts/install.ps1|iex
```

Or download `Parlo-Setup.exe` from this release and press `Ctrl+Alt+D` to dictate.

## Known limitations

- The build is unsigned, so Windows may show **Windows protected your PC** once. The release carries `SHA256SUMS.txt` and a build provenance record.
- Whisper base is the quick start, not the best recogniser. It has no measured word error rate on this project's corpus and Parakeet is the model with the recorded 0.24, so the window switches back as soon as Parakeet is on disk.
- The update swap keeps a `.old` copy of each replaced file beside it. A failed swap leaves the old copy in place, but the folder has to be tidied by hand.
- The global shortcut exists on Windows only, and macOS and Linux are compiled and tested by CI without the window being opened there.
- Portuguese and English remain the only pairs that ship as measured; the others are marked experimental.
