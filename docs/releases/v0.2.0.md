# v0.2.0

Parlo stops being a folder you have to unpack. This release adds a one click installer for Windows, and turns the model list into something a person controls: every model is a row with its size, its own **Download** button and its own **Remove** button, so a machine can carry the recogniser alone and nothing else. Installing Parlo no longer means choosing between a terminal command and a zip file.

## Highlights

- **One click on Windows.** `Parlo-Setup.exe` opens on our own panel: the mark, the paper, the serif and the words that say what Parlo does, instead of the default grey installer. One screen to press through, a progress bar, then **Finish** opens the app. It installs into your user folder, adds the Start menu entry and an entry in Apps and Features with the Parlo icon. No administrator password, no PowerShell to type, no unzip step.
- **Models install one at a time.** The list names the feature each model serves, its size on disk, and whether it is there. **Download** fetches that model and only that model; **Remove** deletes it, refuses while a download is running, and leaves history, meetings, vocabulary and settings untouched.
- **Dictation can be the first thing installed.** **Only what dictation needs** downloads the recogniser by itself, and the page follows that one download instead of waiting for the whole set.
- **The list says who needs what.** A gap reads as «Read aloud needs the Portuguese voice» rather than as a file name, built from the feature each model belongs to.
- **The engine takes the same split.** `--only parakeet`, `--only voice-pt mt-en-pt` and the rest work without the window, so a headless machine gets exactly the units it was asked for.

## Measured

Windows 11 laptop, no GPU, Python 3.12, no administrator rights. Conditions and raw rows live in `docs/BENCHMARKS.md`.

- The package got much smaller in this release: the Windows installer is **44.8 MB** and installs **175 MB**, down from **231 MB** and **655 MB**. The engine bundle alone went from **648 MB to 182 MB**, because a 310 MB `torch_cpu.dll` that nothing on the dictation, translation or voice path imports was being carried along, followed by a 47 MB `transformers` copy that exists only for an optional whisper extra and a 9 MB download accelerator that local inference never uses.
- A silent install took **19 seconds** on the reference machine, and the window does the same work behind a progress bar. The earlier **37 seconds** figure was measured when the package was 220 MB and had to be downloaded first.
- The dictation path is unchanged in cost: **420.7 ms mean and 485 ms p95** per segment over 1 095 segments in a thirty minute run, real time factor **0.11**.
- Cleanup rules: **61.9 µs mean, 55.6 µs median, 102.1 µs p95** per sentence over 10 000 runs.

The installer itself was not timed on a cold cache, and its size is the archive plus a few kilobytes, so it inherits the download above.

## Install

Windows: download `Parlo-Setup.exe` and double click it.

```powershell
irm https://raw.githubusercontent.com/PedroNascimento09/Parlo/main/scripts/install.ps1 | iex
```

macOS and Linux keep the command they had:

```bash
curl -fsSL https://raw.githubusercontent.com/PedroNascimento09/Parlo/main/scripts/install.sh | bash
```

The first start asks for the models: about 800 MB for everything, or the recogniser alone if you only want to dictate.

## Known limitations

- The installer and every archive are **unsigned**: Windows SmartScreen asks once, and there is no certificate behind it.
- The model list covers the recogniser and the two voices. The translation pairs are installed but not listed, because the app cannot yet verify their files, and there is no recommendation from the machine profile, no feature switch and no way to move the model folder.
- Dictation is **tested, not validated**: no real PT-PT recording has been used by anyone but the author, and the acceptance cases are written sentences.
- Meetings can be imported with speakers and timestamps, but Parlo does not summarise them, and it does not capture a meeting on its own.
- Only Portuguese and English, both directions, at machine quality. PT→DE is published as **not validated** by a native speaker.
