Parlo 0.2.5 is the release where the window stops being Portuguese. The interface speaks twenty-one languages, read aloud covers every language Parlo translates to, and Settings answers the question the app used to leave open: which voice, which recogniser and which translation pack belong to the language you chose. Under it, meetings name who said what and when, a desktop shares itself over HTTPS with a PIN, updates follow the channel you pick, and stories render to a chaptered audiobook.

## Highlights

- The interface speaks **21 languages**, kept with the setting and served from one locale table, so a Portuguese, Japanese or Arabic window is the same build.
- Read aloud covers the **eight languages Parlo translates to**: Spanish, Italian, Dutch and Russian voices join the four that existed, and every request speaks with the voice it names instead of borrowing Portuguese.
- Settings recommends a voice, a recogniser and a translation pack for the chosen language, and any of those picks can still be replaced by another model the person installs.
- A meeting's action items and decisions now name the **speaker and the minute**, and the transcript redraws while the meeting is still recording.
- A desktop can serve Parlo over HTTPS with a PIN, and `parlo remote` posts to it after checking the certificate.
- Updates follow the channel you choose: **preview** sees prereleases, **stable** never installs one.
- Stories render to a **chaptered M4B** with cover art, measured loudness and tags, and batch now watches folders for new files.
- Two voices read one sentence back to back, voice packs keep two to eight voices on this computer, and importing a pack installs the voices it names.

## Measured

- Tests: **574** pass across `parlo-core` and `parlo-cli` (**106** of them in `parlo-core`), 0 failed, with `cargo clippy --all-targets -- -D warnings` and `cargo fmt --all --check` clean. Machine: Windows 11, AMD Ryzen 5 3600, 16 GB, no GPU.
- Kokoro 82M against the Portuguese voice, one sentence, CPU only: real time factor **0.390** against **0.070**, and Parakeet recovered **0.929** of the words from it against **0.710**. Its Portuguese is Brazilian and its runtime pulls GPL-3.0 `phonemizer`, so it is measured and not offered; the table is in `docs/BENCHMARKS.md`.
- Recognition and translation are unchanged from 0.2.1.5: Parakeet v3 at **0.113** real time on four threads with 4.95 s of Portuguese audio and a 2.5 s window.

## Install

Download `Parlo-Setup.exe` from this release and run it. It installs for the current user, asks for no administrator, and replaces a running copy in place; once this release is live the app offers it from its own update screen.

Windows will show *Windows protected your PC*. The installer is still not code signed, because there is no certificate behind the project yet: check that the file came from this release page, then choose **More info** and **Run anyway**.

## Known limitations

- The microphone opens on this machine, three seconds captured at 48 kHz while writing this release, but **no spoken sentence was dictated, captioned or translated** for it, so those surfaces stay untested end to end.
- The European Portuguese voice is still the only one Piper publishes. A Brazilian voice reads better by the recognition proxy above and is not offered, because it is not the language this product promises.
- The installer is unsigned, and the window runs on Windows only.
- No external user has run this build.
