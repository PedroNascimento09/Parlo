Parlo can now fetch its own models from inside the app, so a new machine needs no terminal and no setup script. This release also publishes what the first start costs.

## Highlights

- A models panel in the app lists the recogniser and both voices, with the size on disk or `Missing`, so a person can see why nothing is being said before touching anything.
- **Download models** starts the download from the page and the panel refreshes itself until everything is in place, then says the translator is ready.
- The panel never blocks the record button: a missing model is reported where it belongs, not as a dead end.
- `GET /models` and `POST /models` are part of the local API, so a desktop app can show the same state without reimplementing it.

## Measured

- Cold start on Windows 11, no model in memory: `parlo translate` on a 6 s Portuguese clip through the cascade took 18.1 s from process start to the written file, including the Python sidecar, Parakeet TDT 0.6B v3 int8, Argos and Piper. A warmed process is what a conversation uses, and the soak shows it turning a segment around in 420.7 ms.
- Thirty minute soak, same machine, 4 threads: 652 cycles, 1095 segments, p95 485 ms, zero errors, no drift.
- The translator itself is unchanged in this release.

## Install

```bash
cargo build --release -p parlo-cli
./target/release/parlo app
```

If the models are missing, the page offers the download. `parlo update` installs the next release over this one.

## Known limitations

- The models panel was exercised through its endpoints, not clicked through in a browser by the maintainer.
- The download runs the setup script through the Python found at `PARLO_PYTHON`, then `.venv`, then `python` on the path; without any of them the panel reports that it cannot start.
- Windows is the only platform validated end to end.
- Portuguese and English only, machine translation quality, and the interface is still a local page rather than an installed shell.
- A cold start costs about 18 s. The app pays it once per session, not per sentence.
