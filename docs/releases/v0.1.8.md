# v0.1.8

Parlo now types what you say. This release brings dictation from the terminal into the app: a **Dictate** button in the window, a floating island you show and hide with one shortcut, and a `parlo dictate` command, all writing the sentence the person meant instead of every word they said. Behind it sits the first version of the intelligence engine, which fixes self-corrections, hesitations, false starts and repetitions on rules alone, in microseconds, with no model and no network — and can call a model you choose, on this machine or in the cloud with your own key, only when you allow it and only if the answer passes a check that refuses to change meaning. Nothing about translation changed, and a machine that never opens these settings behaves exactly as it did in v0.1.7.

## Highlights

- **Dictation, three ways in.** The window's Dictate button, the floating island on `Ctrl+Alt+D`, and `parlo dictate`, which prints each segment and leaves the text on the clipboard.
- **It writes into the field you were in.** The island remembers which window had the focus when listening began and types there with the keyboard, and falls back to the clipboard with a reason when that window is no longer in front.
- **Self-corrections replace what they correct.** «Quero comprar 2 bilhetes para o cinema, quer dizer, 3 bilhetes para o cinema» becomes «Quero comprar 3 bilhetes para o cinema»; a clarification after «ou melhor» keeps both halves, because the marker alone never decides — overlap does.
- **Original and cleaned text are kept apart**, so the sentence that was heard is never lost and `original` gives it back untouched.
- **The intelligence engine (PIE)** runs in four modes: rules only, a model on this machine, the cloud provider you picked, or automatic. Cloud is never reached without the allow-cloud switch and a key you stored, so nothing is sent anywhere by default.
- **Your key stays yours.** OpenAI, Anthropic, Google Gemini and any OpenAI-compatible server, with the key stored by the operating system — DPAPI on Windows, the keychain on macOS, the secret service on Linux — and never in the config file, a log or an error message. With no credential store, Parlo refuses to save the key instead of writing it in clear.
- **A model's answer cannot quietly rewrite you.** The reply must be JSON with a `text` field, cannot introduce a number or a proper name that was not said, and cannot grow past 1.6× or shrink below 0.4×. Anything else falls back to the rules with the reason recorded.
- **How dictation is cleaned up** is a panel in the app: engine, how much may change, provider, model, local address, allow-cloud switch, the key, and a button that sends one sentence to prove the setup works.
- `PARLO_GLOSSARY.md` names the parts once: PAVE, PSTE, PTE, PIE, PIMO and PME, each with its responsibility and the code it lives in.

## Measured

Windows 11 laptop, no GPU, Python 3.12, unless the line says otherwise. Conditions and raw rows live in `docs/BENCHMARKS.md`.

- Cleanup rules only, 10 European Portuguese and English sentences of 8 to 18 words, 10 000 runs: **61.9 µs mean, 55.6 µs median, 102.1 µs p95** per sentence. No model is started for this, and it runs in every mode.
- One segment end to end through the cascade, recognition included: **420.7 ms mean, 485 ms p95**, over 30 minutes and 1 095 segments with no errors and no drift.
- Streaming on a European Portuguese voice: first partial at **849 ms**, final text at **3 356 ms**, final word error rate **0.231** for Parakeet.
- Cold start with every model loaded: **18.1 s**.

No cloud provider was measured. Not one request was made to a real provider with a real key while building this, which is why the release says the panel is tested and not validated.

## Installing it

Download the archive for your system, unpack it, and double-click `parlo-app`. The first run offers the models your device can run, about 800 MB, with a progress counter; nothing works offline until they arrive.

```
parlo install      # optional: copy it into your user folder and add a menu entry
```

Then press `Ctrl+Alt+D` to dictate, or use the Dictate button in the window. Dictation needs no voice model and no translation package.

## Known limitations

- Dictation is **tested, not validated**: it has not been used with a real PT-PT recording by anyone but the author, and the acceptance cases are written sentences, not a corpus of speech.
- The intelligence engine has never spoken to a real provider. A refused key, a rate limit and a timeout are covered by tests with an injected transport, not by a live run.
- The cloud route has no price and no spending cap: Parlo does not bundle provider prices, so it shows none rather than an invented one.
- The dictation island does not check for updates; the window does, and it is the window that installs one.
- Meetings can be imported with speakers and timestamps, but Parlo does not yet capture a meeting on its own.
- There is no virtual microphone and no Live mode for calls, so a call application still sees the system microphone.
- Only Portuguese and English, both directions, at machine quality. PT→DE is published as **not validated** by a native speaker.
- The window is unsigned: Windows SmartScreen asks once, and there is no installer.
