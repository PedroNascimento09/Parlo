Parlo 0.2.1.2 fixes the window. In 0.2.1 and 0.2.1.1 a broken script made every button on the page do nothing, including the one that offers the update; that fault is repaired here, and the build now refuses to ship a page script that does not parse.

## Highlights

- The page answers clicks again, and CI runs `node --check` on the page script so a syntax error cannot reach a release again.
- Translation, read aloud and captions can be switched off in Settings without deleting a single model.
- The engine says what this machine can do and why, naming cores, memory and AVX2, and writes each change to `logs/engines.jsonl`.
- Both translation pairs are listed with their real size, and a running download can be stopped.
- The model folder can move to another drive: it copies, compares the bytes, and only then deletes the old folder.
- A voice profile holds a real ten to thirty second sample, which can be heard, sealed with the Windows account, exported with a synthetic marker, and deleted.
- Colours and type come from the tokens of section 85.

## Measured

- Tests: **118** in `parlo-cli` and **79** in `parlo-core`, with `clippy -D warnings`, `fmt --check` and `node --check` clean.
- Contrast on the real pairs, light theme: ink on canvas **16.65**, ink-soft on surface **11.84**, muted on surface **5.98**, error **6.66**, ok **4.85**, listen **5.50**, tech **11.01**; dark theme: **16.44**, **11.22**, **6.47**, **5.80**, **8.31**, **7.95**, **8.64**.
- Model sizes read from disk: recogniser **670.5 MB**, each voice **63.2 MB**, Portuguese to English **80.1 MB**, English to Portuguese **79.6 MB**.

## Install

If you are on 0.2.1 or 0.2.1.1, run `Parlo-Setup.exe` from this release once: the page in those versions cannot start an update, because the fault is in it. From 0.2.1.2 the update runs inside the app.

## Known limitations

- The engine that turns a voice sample into speech is not in this build.
- No Portuguese voice from Portugal has been validated, so read aloud ships the voice it has and does not call it natural Portuguese.
- `warn` on the light canvas measures **3.51**, so it is used only for large text, icons and fills.
- The installer is not signed, and macOS and Linux are not supported.
