# v0.1.7

Parlo opens in a window of its own, records consent before it will hold a voice profile, and translates without the Argos runtime. This is the first release the licence gate allows out: the translation stage left the AGPL dependency chain behind, so the archives exist at all. A version with this number was tagged and withdrawn earlier the same day, when the gate refused to build it; nothing from that attempt was published.

## Highlights

- `parlo-app` opens the interface in a native window, starts its own engine on a free loopback port and stops it when the window closes.
- Translation reads an OPUS-MT package through CTranslate2, so the engine needs only numpy and sherpa-onnx and carries no Argos code.
- `parlo_cascade/packs.py` downloads those packages itself, with a size ceiling, a path check on the archive and a recorded SHA-256.
- The app creates voice profiles that store who the voice belongs to, the purpose and the notice you were shown, and delete every file on request.
- Streaming recognition reports `partial`, `stable`, `final` and `corrected` text, and `parlo stream <file.wav>` prints them as they arrive.
- The code is Apache-2.0 from this release on; earlier releases keep the MIT text they were published with.
- The licence gate now proves its own exemption: it asks cargo for each release target's graph and fails if a crate marked not shipped ever appears in one.

## Measured

Windows 11 laptop, no GPU, 4 threads, warm process, unless the line says otherwise. Conditions and raw rows live in `docs/BENCHMARKS.md`.

- Translation over the 24 sentence corpus: **114 ms median** PT→EN (p95 131 ms) and **111 ms** EN→PT (p95 128 ms), with 12 of 12 sentences finished in both directions.
- One segment end to end, recognition and voice included: **699 ms mean**, p95 940 ms, over 66 segments in a two minute soak with no errors and no drift.
- Cold start with every model: **18.1 s**.
- Streaming on a European Portuguese voice: first partial at **849 ms**, final text at **3.36 s**, final word error rate **0.231** for Parakeet.

## Installing it

Download the archive for your system, unpack it, and double-click `parlo-app`. The first run offers the models your device can run, about 800 MB, with a progress counter; nothing works offline until they arrive.

```
parlo install      # optional: copy it into your user folder and add a menu entry
```

## Known limitations

- The window is unsigned. Windows SmartScreen asks once, and there is no `.msi`, `.dmg` or `.deb`.
- Voice cloning does not exist: a profile records the consent and nothing else, so every sentence is spoken by the neutral voice.
- There is no virtual microphone and no Live mode, so a call application still sees the system microphone.
- Only Portuguese and English, both directions, at machine quality: `O João` can come back as `John`, some European wording slips, and a pronoun is sometimes guessed.
- The window has been run by hand on Windows only. It compiles and is tested on macOS and Linux in CI, and has not been opened there.
