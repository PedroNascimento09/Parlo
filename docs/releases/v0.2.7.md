Parlo 0.2.7 fixes dictation into the window you were already typing in. The sentence is pasted through the clipboard instead of typed key by key, the clipboard you had comes back 1.5 s after a successful paste, and a paste that cannot land keeps the sentence on the clipboard with one instruction. The island opens without waiting for the engine and stays at the bottom of the monitor under the cursor.

## Highlights

- Dictation pastes the sentence, so long text and Electron windows keep every letter.
- The clipboard you had comes back 1.5 s after a successful paste.
- A failed paste leaves the sentence on the clipboard and the island says to press Ctrl+V.
- The keyboard hook no longer waits on the engine, so a busy dictation cannot stall typing elsewhere.
- The island sits at the bottom of the monitor under the cursor.
- Saved phrases, bullet commands and live words while speaking are in this release.

## Measured

- Tests: 601 pass with `cargo test --workspace`, 0 failed; `cargo clippy --all-targets -- -D warnings` and `cargo fmt --all --check` clean. Machine: Windows 11, AMD Ryzen 5 3600, 16 GB, no GPU.
- The paste path ran against a Windows text box: `POST /insert` answered `{"inserted":true}` and the box held `Parlo paste test.` on Windows 11.
- Dictation on the same machine, a 7.5 s Portuguese clip, 2 threads: 4591.4 ms on the first call, then 1212.5 ms and 1123.6 ms, from `docs/BENCHMARKS.md`.
- The clipboard restore waits 1.5 s. The previous clipboard is not read, stored or logged.

## Install

Download `Parlo-Setup.exe` from this release and run it. It installs for the current user, needs no administrator, and replaces a running copy in place. Once this release is live, the app offers it from its own update screen. `winget install Parlo` works after the winget repository accepts the manifest; the manifest is submitted with this release.

Windows will show *Windows protected your PC* because the installer is unsigned: check that the file came from this release page, then choose **More info** and **Run anyway**.

## Known limitations

- The installer is unsigned.
- The paste needs the window in front. When Windows refuses to raise it, the sentence stays on the clipboard and the island says so.
- `winget install Parlo` depends on winget review, which is outside this repository.
- The package manifests in this tag carry the previous checksums for the archives; they are updated on `main` once the build finishes, and the winget manifest is pointed at the new installer then.
- macOS and Linux are compiled and tested by CI, but the window has not been opened there.
- The first dictation after start still waits for the engine to warm up.
