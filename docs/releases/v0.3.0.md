# v0.3.0

Parlo is now something a person can install with one command and use without Python, Rust or a terminal beyond the first start. This release closes the foundation and engines milestones and ships the dubbing preview that arrived early: the local service has a configuration file, a token and protection against hostile pages, recognition runs on Parakeet or Whisper with a published comparison, the app chooses the language pair and the recogniser, dubs files offline, shows live captions, and updates itself in place.

## Highlights

- One archive that works without Python: `parlo` plus a self-contained `parlo-engine` folder.
- First run downloads the models from inside the app, verified against the digest the server publishes.
- `parlo dub video.mp4 --to en` dubs offline with subtitles, and the app takes a dropped file.
- Captions mode translates the microphone as text, with no speech synthesis.
- Live mode in the app translates continuously and speaks each window in order.
- `parlo speakers` and `parlo listen --play --speaker N` play the translated voice to any output device.
- Languages and recogniser are chosen in the page and saved to the config file.
- `parlo install` copies everything into a per-user directory with a menu entry and an icon.
- The local API gained `/settings`, `/dub`, `/models` and `/update`, and now refuses a foreign `Host` and cross-origin writes.

## Measured

Reference machine: 12 core desktop CPU, no GPU, Windows 11, Python 3.12, 4 threads unless stated.

- Recognition speed: Parakeet real time factor **0.113** against Whisper base **0.309** on the same 4.95 s clip.
- Recognition accuracy, 24 Portuguese sentences, clean / 20 dB / 10 dB: Parakeet **0.215 / 0.199 / 0.197** word error rate, Whisper small **0.217 / 0.242 / 0.309**.
- Continuity: **30.0 minutes** of looped speech, 1095 segments, **420.7 ms** mean per segment, zero errors, and the last ten cycles 58 ms faster than the first ten.
- Cold start: **18.1 s** from process start to a translated file, models included.
- Captions: **958 to 1266 ms** of processing on a 1.2 s window, so a caption appears about **2.2 s** after the words start.
- Dubbing: a 6.6 s Portuguese clip dubbed to English, output peak **-0.5 dBFS**.
- Background ducking with `--keep-background`: original at 0.55 between lines, about 0.10 under a line, 0.15 s fades.

## Install

Download the archive for your system, unpack it, and run `parlo app`. The folder `parlo-engine` must stay beside `parlo`. The first start downloads about 800 MB of models into your user data directory, once; after that everything runs offline.

```
parlo install
```

copies it into a per-user directory and adds a menu entry. `parlo uninstall` removes it and keeps your models.

## Known limitations

- Dubbing timing is approximate: a translation longer than its slot is spoken up to 18 percent faster and can overlap the next line.
- `--keep-background` keeps music and effects but performs no source separation, so the original voice is still audible between lines.
- There is no virtual microphone yet. On Windows and macOS the route into a call is a virtual cable plus `parlo listen --play --speaker N`; on Linux the PipeWire microphone exists.
- Captions at 2.2 s miss the sub-2 second design target for the basic profile; a shorter window would reach it at the cost of accuracy.
- The packaged engine is about 806 MB unpacked, mostly because the translator imports torch through stanza.
- Only Portuguese and English have models today, in both directions.
- Windows is the only platform exercised by hand. Linux and macOS are covered by unit tests and CI builds, and the release archives for them have never been run.
