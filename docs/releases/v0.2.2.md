Parlo 0.2.2 is the version that stops looking like a prototype. A new mark, a warmer palette, one clear sentence about what Parlo is doing right now, and a microphone that no longer asks for permission every time the app starts. The installer gained a licence page, an uninstall entry, a version in its file name, and a signing hook that stays quiet until a certificate exists.

## Highlights

- A new Parlo mark, drawn as a rounded tile with a speech bubble and a sound inside it, used for the window, the tray, the installer wizard and the shortcut icon.
- Home leads with one sentence in plain words: `Ready to dictate`, `Listening`, `Writing it down`, `Typing into your app`, `Done`, `Needs attention`, `Thrown away`. Four small facts sit under it instead of eight fields of jargon.
- The palette moved to warm paper with terracotta and deep teal, headings in a serif face, and a rail that shows where you are. No gradients, no glass, no shine.
- Parlo now grants itself the microphone permission on Windows, so the app never shows a browser-style permission dialog and never mentions a local address.
- The three shortcut keys are settings of their own: dictate, hands free and captions, each validated, refused when it repeats another, and refused when Windows says another program already owns the combination.
- The tray lists the three modes and the five destinations. The window no longer starts a mode.
- Settings is eight sections of real fields, and About reads the version as `v0.2.2`.
- The installer is a per-user install under `%LOCALAPPDATA%\Programs\Parlo`: no administrator prompt, a licence page, an uninstall entry, a running copy closed before the files are replaced, `Parlo-0.2.2-Setup.exe` as the file name, and the licence and notices copied beside the program.

## Measured

- Tests: **125** in `parlo-cli` and **82** in `parlo-core`, with `cargo clippy --workspace --all-targets -- -D warnings` and `cargo fmt --all --check` clean.
- `GET /settings` answers with `shortcut`, `hands_free` and `captions`; a duplicate key returns **409** and names both, an unusable key returns **400**, and a valid key answers **200** with the stored value.
- Nothing in this release changes recognition or translation, so the latency numbers from 0.2.1.5 still apply: `POST /dictate` on ten seconds of silence took **2.47 s**, reported **2438 ms**.

## Install

Download `Parlo-0.2.2-Setup.exe` from this release and run it. From 0.2.1.2 onward the update also arrives inside the app with these notes beside the button. If a copy of Parlo is running, setup closes it and asks it to start again after the files are in place.

Windows may show *Windows protected your PC* on the first download of a new version. The installer is not code signed yet: there is no certificate behind this project, so SmartScreen has no publisher to trust and treats every new file as unknown. Verify the file came from this release page, then choose **More info** and **Run anyway**. The same warning will appear until a certificate is bought and every release is signed with it.

## Known limitations

- The installer is unsigned, so the SmartScreen warning stays until a code signing certificate exists. The release workflow is ready to sign both binaries and the installer as soon as `WINDOWS_SIGNING_PFX_BASE64` and `WINDOWS_SIGNING_PASSWORD` are set; that path has not been exercised yet.
- The microphone permission is granted for the app's own window. Windows Settings, Privacy, Microphone, "Let desktop apps access your microphone" still has to be on.
- The global shortcuts are Windows only. On macOS and Linux the log says so and the tray menu still dictates.
- macOS and Linux are not supported for the window or the installer. Only Windows gets a one click setup.
- The meeting summary still needs a local model this build does not run offline.
- A meeting records the microphone only; sound from another application is not captured yet.
