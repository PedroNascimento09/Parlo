Parlo 0.2.1.3 speaks Portuguese from Portugal. Read aloud now installs the European voice `pt_PT-tugão-medium` instead of the Brazilian one, because this project's own twenty sentences scored 0.24 word error rate with the European voice and 0.67 with the Brazilian. Removing a voice or a translation pair switches off the feature that needed it, and every text colour in the window clears 4.5:1.

## Highlights

- Read aloud speaks European Portuguese. The Brazilian voice stays one command away: `setup_models.py --voice pt_br`.
- Removing a voice or a translation pair switches that feature off in Settings, and the list says which switch went off and which model to download again.
- The accent colour is no longer used as text. Links and hover words use the deeper accent, because the accent measured 4.29 on surface and 3.98 on canvas.
- The button ink on the accent measures 4.57, up from 4.33.
- The reference battery takes `--voice` and records the voice in its report, so a number is never read against the wrong voice.
- `docs/MODEL_MANAGER.md` now states what the model panel does and what it still does not.

## Measured

- Tests: **120** in `parlo-cli` and **79** in `parlo-core`, with `clippy -D warnings`, `cargo fmt --check` and `node --check` clean.
- Word error rate on 20 European Portuguese sentences, Parakeet TDT 0.6B v3 int8, Windows 11, 4 threads, decode every 0.4 s: **0.24** with `pt_PT-tugão-medium`, **0.67** with `pt_BR-faber-medium`.
- Contrast, light theme: accent ink on the accent **4.57**, deeper accent as text **6.68** on surface and **6.20** on canvas, ink on canvas **16.65**, muted on surface **5.98**. Dark theme: **6.06**, **7.08**, **7.62**, **16.44** and **6.47**.
- Every text pair in the window clears 4.5:1. The warning colour measures **3.79** on surface and nothing is set in it.

## Install

Download `Parlo-Setup.exe` from this release and run it. From 0.2.1.2 onward the update arrives inside the app, with these notes next to the button; on 0.2.1 or 0.2.1.1 run the installer once, because the page in those versions cannot start an update.

## Known limitations

- The engine that turns a voice sample into speech is not in this build.
- Read aloud is a neutral voice, and no Portuguese voice from Portugal has been judged by listeners.
- Models already on disk are not moved. A machine that installed 0.2.1.2 or earlier keeps the Brazilian voice until the European one is downloaded and the old one removed.
- The model list shows no memory, no speed and no loaded state, an interrupted download starts again from the beginning, and a folder that already holds models is not adopted after a digest check.
- The installer is not signed, and macOS and Linux are not supported.
