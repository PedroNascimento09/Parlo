Parlo now updates itself. `parlo update` reads the release feed, downloads the build for your system, and replaces the binary in place, so a new version never means uninstalling and installing again.

## Highlights

- `parlo update --check` says which version is current and which is latest, and changes nothing.
- `parlo update` downloads the archive for Windows, macOS or Linux, stages it, and swaps it over the running binary about two seconds after the old process exits.
- The previous binary stays next to the new one as `parlo.previous`, so rolling back is a rename, not a reinstall.
- The app banner and the command line agree: both read the same release feed, and the stable channel is the tagged release.
- Release titles are the version alone from now on, `vX.Y.Z`, with no codename.

## Measured

- `parlo update --check` against the live feed from version 0.1.1, on Windows 11, returned `parlo 0.1.1 is up to date, the latest release is 0.1.1` in one request.
- The translator is unchanged from v0.1.1: 20 s of Portuguese speech through the cascade engine on a laptop Realtek microphone, 4 threads, produced 4 sentences and the first translated audio 5.63 s after start.

## Install

```bash
cargo build --release -p parlo-cli
./target/release/parlo app
```

Updating from here on is one command: `parlo update`.

## Known limitations

- The swap waits for the running process to exit, so the binary that keeps translating is the old one until you restart; the command says so.
- Parlo still has no installer. The release archives are a binary each, which is enough to update in place but not to put an icon in a menu yet.
- Windows is the only platform validated end to end. The macOS and Linux archives build in CI and their update path is written but was not run by the maintainer.
- The update download runs through the system's own tools (PowerShell on Windows, curl elsewhere), so a machine without them cannot update itself.
- Portuguese and English only, machine translation quality.
