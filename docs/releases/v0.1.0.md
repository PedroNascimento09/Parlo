The first tagged release of Parlo: a local, offline Portuguese to English and English to Portuguese translator for your microphone. Audio never leaves the machine and there is no telemetry. Everything runs on the CPU, from a command line, with no account and no cloud.

## Highlights

- Command line only: `doctor`, `demo`, `translate`, `engines`, `profile`, `mic`, `record`, `listen`, `serve`.
- The pipeline cuts the microphone into 20 ms frames, applies a voice gate, resamples 48 kHz to 16 kHz and hands frames to the engine.
- Three engines behind one boundary: `echo` with no models for testing, `cascade` with Parakeet TDT 0.6B v3 int8 through sherpa-onnx plus Argos Translate and Piper synthesis, and an optional `sidecar` for Hibiki-Zero.
- `parlo serve` exposes an authenticated local API on `127.0.0.1` that accepts 16 kHz mono PCM16 WAV and returns the same format.
- `parlo mic setup` automates a PipeWire virtual microphone on Linux.
- A quiet microphone still works: `parlo record` peak-normalises towards -1 dBFS with a +24 dB ceiling, the pipeline applies automatic gain after the voice gate up to +24 dB, and the voice gate opens at -55 dBFS.

## Measured

- Recognition only, 4.95 s of synthetic Portuguese speech, 4 threads, 2.5 s window: Parakeet v3 RTF 0.113 against Whisper base 0.309.
- Whole cascade including translation and synthesis, ten 6 s clips recorded from a laptop Realtek microphone on Windows 11, 4 threads: Parakeet mean RTF 0.45, Whisper base mean RTF 1.27.
- 20 s of live Portuguese speech on the same machine: 4 sentences translated, 6.55 s of translated audio, first translated audio 5.63 s after start, input gain +24.0 dB.

## Install

```bash
cargo build --release -p parlo-cli
python engines/cascade/scripts/setup_models.py
cargo run --release -p parlo-cli -- listen out/live.wav --seconds 10
```

The models are a download of about 640 MB and need Python 3.12.

## Known limitations

- Validated end to end only on Windows by the maintainer; the Linux and macOS paths are covered by unit tests alone.
- Portuguese and English only.
- Machine translation quality, not human quality.
- First translated audio arrives around 5 s after start, because the cascade needs a 2.5 s segment before it can begin.
- No virtual microphone on Windows or macOS yet.
- Hibiki-Zero weights are CC BY-NC-SA 4.0, which is why that engine is optional. Piper is GPL-3.0-or-later and stays a separate, user-installed program.
