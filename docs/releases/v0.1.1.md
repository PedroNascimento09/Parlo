The first interface: `parlo app` opens the translator in your browser, served by the same binary that already does the work. Nothing new is installed, no driver, no account, and the microphone audio still never leaves the machine.

## Highlights

- `parlo app` starts the local server, opens the page with the session token, and shows the translator without a single command in front of you.
- One control records while you hold it or after a click, and the translated voice plays back when it arrives.
- A live input level meter, so you can see the microphone working before you speak.
- The page shows the engine, the running version, and clear sentences for the three failures that actually happen: permission refused, no microphone, translation error.
- An update banner checks the latest release and links the notes. It never installs anything without a click.
- Every push to `main` now publishes the `nightly` prerelease, so a fix is downloadable the same day without waiting for a tag.

## Measured

- The translator behind the app is unchanged from v0.1.0: 20 s of Portuguese speech through the cascade engine on a laptop Realtek microphone, Windows 11, 4 threads, produced 4 sentences, 6.55 s of translated audio, and the first translated audio 5.63 s after start.
- The page is served by the same process that translates. It adds no dependency, no build step, and no external request beyond the update check.

## Install

```bash
cargo build --release -p parlo-cli
./target/release/parlo app
```

Then speak. The page opens by itself; keep the terminal window open while it runs.

## Known limitations

- The update is offered, with its notes, but installing it from inside the app is not implemented yet. For now the banner links the release page.
- Windows is the only platform validated end to end. Linux and macOS are covered by unit tests alone.
- The browser asks for microphone permission the first time, and the page needs a browser recent enough for `color-mix()`.
- Portuguese and English only, machine translation quality.
- The first translation arrives after a few seconds of speech, because the cascade needs a 2.5 s segment before it can begin.
