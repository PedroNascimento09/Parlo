# v0.1.9

A patch for the release before it. v0.1.8 shipped dictation with one wrong argument: the app asked the engine for the other language, so a dictation made in Portuguese came back translated into English, and on a machine without the translation package it failed instead of writing. This release resolves the target language before the request reaches the engine — the language spoken, unless the person asked for another one — and the island now learns about a newer release when it opens, so the surface that never shows the window is no longer the one left behind.

## Highlights

- **Dictation writes the language you spoke.** `/dictate` used to hand the empty «Dictation writes» straight to the engine, which read it as the other side of the pair: `pt` in, `en` out. The endpoint now resolves the target once, and both the text and the language recorded in the history come from that resolution.
- **A test holds the rule**: the language spoken by default, another one only when it is asked for.
- **The dictation island checks for updates.** It asks the same `/update` route the window uses, says «v0.1.9 is available, you are on v0.1.8. Open Parlo to update.» in its hint, and installs nothing on its own. A failed or rate limited lookup shows no version rather than a wrong one.

## Measured

Windows 11 laptop, no GPU, Python 3.12. Conditions and raw rows live in `docs/BENCHMARKS.md`.

- The dictation path itself did not get slower or faster: this release changes which language is asked for, not how audio is processed. The published segment cost still stands at **420.7 ms mean and 485 ms p95** over 1 095 segments in a thirty minute run.
- Cleanup rules, unchanged in this release: **61.9 µs mean, 55.6 µs median, 102.1 µs p95** per sentence over 10 000 runs.

## Installing it

Download the archive for your system, unpack it, and double-click `parlo-app`. The first run offers the models your device can run, about 800 MB; nothing works offline until they arrive. If Parlo is already installed, the window offers this version and installs it on a click.

```
parlo install      # optional: copy it into your user folder and add a menu entry
```

## Known limitations

- Dictation is still **tested, not validated**: no real PT-PT recording has been used by anyone but the author, and the acceptance cases are written sentences.
- The cloud route has never spoken to a real provider, and it shows no price or spending cap.
- Meetings can be imported with speakers and timestamps, but Parlo does not yet capture a meeting on its own.
- There is no virtual microphone and no Live mode for calls.
- Only Portuguese and English, both directions, at machine quality. PT→DE is published as **not validated** by a native speaker.
- The window is unsigned: Windows SmartScreen asks once, and there is no installer.
