Parlo 0.2.3 is the release where meetings become something a person can keep and other programs can read. A transcript names its action items with an owner and the due phrase someone actually said, keeps its decisions while a later one replaces an earlier one on the same topic, and leaves the app as a Markdown file. `parlo mcp` hands those files to any MCP client, and the virtual microphone has a path on Windows instead of a Linux-only refusal.

## Highlights

- A meeting's action items are read from the transcript by rule: the owner is the speaker or the person named before the verb, the due phrase is the one the line used, and a denial is not a promise.
- A meeting's decisions are kept, and a later decision on the same topic replaces the earlier one, naming the minute that was replaced.
- Every meeting downloads as Markdown: title, decisions, action items, notes, and the transcript with who spoke.
- `parlo mcp` answers an MCP client on stdio with four tools: `list_meetings`, `ask_meetings` with citations, `meeting_notes`, and `recent_dictations`.
- On Windows, `parlo mic status` and `parlo mic setup` recognise VB-CABLE, VoiceMeeter or Scream, print the index for `parlo listen --play --speaker N`, and say which side of the cable the call must pick.
- `parlo retention --days 30` counts the meetings that would expire and deletes only with `--apply`; a window of 0 days is refused.

## Measured

- Tests: **198** in `parlo-cli` and **82** in `parlo-core`, with `cargo clippy --workspace --all-targets -- -D warnings` and `cargo fmt --all --check` clean. Machine: Windows 11, 12 core CPU, no GPU.
- Nothing here changes recognition or translation, so the numbers from 0.2.1.5 still apply: `POST /dictate` on ten seconds of silence took **2.47 s** and reported 2438 ms; Parakeet holds a real time factor of **0.113** on 4 threads with 4.95 s of Portuguese audio and a 2.5 s window, as recorded in `docs/BENCHMARKS.md`.
- `parlo mcp` answered `initialize` with protocol `2024-11-05`, returned a real meeting and its two speakers from `list_meetings`, sent no reply to a notification, and answered `-32700` to a line that was not JSON.
- `parlo doctor` on this machine, with 0 of 8 models installed, prints `not ready: 2 checks need attention` and now names the next step; `parlo retention --days 30` deleted nothing, because it prints before it deletes.

## Install

Download the installer attached to this release and run it. It installs for the current user, asks for no administrator, and replaces a running copy in place; the app also offers this version from its own About screen once it is published.

Windows will show *Windows protected your PC*. The installer is still not code signed, because there is no certificate behind the project yet: verify that the file came from this release page, then choose **More info** and **Run anyway**.

## Known limitations

- No model was downloaded for this release, so the first session was not run. Dictation, captioning and meeting capture are **implemented and not verified on this machine**.
- The streaming path, the meeting recorder and the Windows microphone routing were never exercised with a real microphone or a real virtual cable.
- Windows gives no program a microphone of its own without a signed kernel driver, so Parlo routes an existing cable and installs no driver.
- The meeting summary still needs a local model this build does not run offline, and a meeting records the microphone only, not the sound of another application.
- The installer is unsigned, and the window runs on Windows only.
- No external user has run this build; G2 remains the author's own first session.
