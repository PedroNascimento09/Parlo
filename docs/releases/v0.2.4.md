Parlo 0.2.4 is the release where the window became a product rather than a set of pages: one navigation, one type scale, cards that hold their shape, and empty sections that name the next step. It brings the work that arrived with it, dictation undo from the tray, snippets with placeholders, per-program writing styles, a searchable history, and it cuts the voice page down to the three things a clone needs.

## Highlights

- The whole window uses one design system: a pill navigation, a two column Home, a card per surface, serif headings, one green signal and a full dark theme, with no web font and no CDN.
- Settings reads as six tabs of hairline rows, Programs sits under Dictation, and every pane shares one width and one rhythm.
- Insights is its own section, and an empty Insights or Meetings panel shows a card with the next step and a button that does it; Voice is the form itself plus one line of state.
- Undo takes the last dictation back from the tray or a global shortcut, and the key is set in Settings beside the other three.
- Snippets fill `{{date}}`, `{{time}}` and `{{name}}` when they are written, and export and import as one tab separated file.
- A program carries its own writing style and language, a correction can save its word into the vocabulary, and the history searches and rewrites a line without speaking again.
- Voice asks for a name, a language and whose voice it is. A third party needs the permission box, and nothing else is requested.

## Measured

- Tests: **254** in `parlo-cli` and **83** in `parlo-core`, 0 failed, with `cargo clippy --workspace --all-targets -- -D warnings` and `cargo fmt --all --check` clean. Machine: Windows 11, 12 core CPU, no GPU.
- Nothing here changes recognition or translation, so the published engine numbers still apply from 0.2.1.5: Parakeet v3 at a real time factor of **0.113** on 4 threads with 4.95 s of Portuguese audio and a 2.5 s window, and `POST /dictate` on ten seconds of silence at **2.47 s**, both with their conditions in `docs/BENCHMARKS.md`.
- Interface measured in this build's own server at 1180 px: the voice form lays out three columns of **306 px**; at 640 px it is one column of **574 px**; horizontal overflow is **0** at both widths and the page carries no Portuguese text.
- The voice endpoint accepts a profile with no declared purpose: `POST /voice` answered **201** and stored `local voice cloning and playback` with the scope `on this computer`, while a third party profile without the permission box answered **400**.

## Install

Download `Parlo-Setup.exe` from this release and run it. It installs for the current user, asks for no administrator, and replaces a running copy in place; once the release is live the app offers it from its own update screen.

Windows will show *Windows protected your PC*. The installer is still not code signed, because there is no certificate behind the project yet: check that the file came from this release page, then choose **More info** and **Run anyway**.

## Known limitations

- No model was downloaded for this release, so dictation, captioning, translation and meeting capture were **not run here**. Install a model and the app reports where it stands.
- A voice profile is still only a name, a language and a consent record: the ten second sample is recorded when the voice engine ships, and the page says so instead of pretending.
- The interface was opened at 1180 and 640 px in the app's own server; 900 px and the narrowest window share the same rules but were not each opened.
- The installer is unsigned, and the window runs on Windows only.
- No external user has run this build.
