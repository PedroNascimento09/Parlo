Parlo 0.2.10 makes dictation write live and takes back exactly what it wrote. Partial transcripts now appear in the field as you speak and the final sentence replaces them once, undo removes precisely the inserted text, and the pending dictation recovery is sealed with Windows account protection instead of stored as plain text. The release also carries the interface locales one file per language, a content security policy on the native window, and a test gate that fails when production code gains an unwrap.

**Highlights**

- Dictation writes live: partials appear in the field as you speak, each update replacing the previous fragment, and the final transcript replaces it once when recording stops.
- Undo for the last dictation removes exactly the text Parlo inserted, and writing stops rather than stealing focus when the target window is no longer in front.
- Snippets expand anywhere inside a dictation, and a "delete last word" voice command works in English, Portuguese, Spanish, French and German.
- The pending dictation recovery is sealed with Windows account protection at rest; older plain rows still open.
- The native window carries a content security policy, the interface strings live one file per language, and a test gate now fails when production Rust gains an unwrap outside tests.

**Measured**

- Fresh run on this machine at this tag: 650 Rust tests pass with 0 failures (`cargo test --workspace`), 86 web tests pass, `cargo clippy --workspace --all-targets -- -D warnings` is clean, `cargo fmt --check` passes, and the engine suites pass under `unittest` (376 tests in `engines/cascade`, 27 in `engines/hibiki` with 1 skipped).
- Dictation speed is unchanged from the published benchmark on the reference machine (Windows 11, 12-core CPU, no GPU, Parakeet TDT 0.6B v3 int8 on 4 threads, fixed 5.00 s Portuguese clip): 375.0 ms median from end of audio to text with silence trimming, full conditions in `docs/BENCHMARKS.md`.

**Install**

Windows: download `Parlo-Setup.exe` from the v0.2.10 release, or run `winget install Parlo`. Mac and Linux: download the matching `parlo-macos-aarch64.tar.gz` or `parlo-linux-x86_64.tar.gz` archive, extract it, and run `parlo app`. Both carry `SHA256SUMS.txt` and a build provenance record.

Parlo checks the latest release when the app starts and offers the update with these notes beside it. Nothing is installed without a click.

**Known limitations**

- The build is unsigned, so SmartScreen may warn once on Windows.
- Dictation has not been validated end to end on Windows with external users; the manual matrix in `docs/TESTING.md` is the gate, and this release does not claim it passed. There is no external user feedback yet.
- The package manifests in this tag carry the previous checksums for the archives; they are updated on main once the build finishes.
- Portuguese and English remain the only shipped speech pair; the other downloadable pairs stay experimental until measured here.
