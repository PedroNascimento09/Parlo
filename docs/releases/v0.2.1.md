Parlo 0.2.1 gives the voice profile something to carry and makes the model list honest about itself: a sample you can hear, seal, export and delete, and an entry for every model that says why it is offered.

## Highlights

- A voice profile holds a ten to thirty second sample recorded in the window. A short take is refused with its measured length, and a silent one is refused with the reason.
- **Play sample** hears the take back. **Export** writes one file that names the origin, the consent record and marks the audio as synthetic. **Delete** removes the sample and everything made from it, and says that copies in system backups are outside Parlo's reach.
- **Keep the sample sealed with my Windows account** stores the sample as DPAPI ciphertext and unseals it only to play or export.
- Every model says why it is the one offered, with the machine read at that moment: cores, memory and whether AVX2 is there.
- **Stop the download** ends a running download, and what already arrived stays on disk.
- Both translation pairs are listed with their size on disk and their own Download and Remove buttons.

## Measured

- Tests on the reference machine, Windows 11, Rust release build: **111** in `parlo-cli` and **77** in `parlo-core`, with `clippy -D warnings` and `fmt --check` clean.
- Sizes read from disk on the reference machine: recogniser **670.5 MB**, Portuguese voice **63.2 MB**, English voice **63.2 MB**, Portuguese to English **80.1 MB**, English to Portuguese **79.6 MB**.
- Recognition is unchanged from 0.2.0: Parakeet TDT 0.6B v3 int8, 4 threads on a 12 core CPU, 4.95 s of Portuguese audio, 2.5 s window, five runs, mean **RTF 0.113**.

## Install

Download the installer from this release and run it, or build from source with `cargo build -p parlo-cli --release`. The installer is not signed, so Windows shows its usual warning.

## Known limitations

- The engine that turns a sample into speech is not in this build. A profile can be recorded, heard, exported and deleted; it cannot yet speak a translation.
- Sealing uses the Windows account, so the option is Windows only.
- A cancelled download keeps the files that arrived, but Parlo does not promise where the download tool resumes from.
- No recogniser or translation pair has been validated by a native speaker. G0 and G2 stay open.
