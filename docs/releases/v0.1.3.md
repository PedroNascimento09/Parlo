The app is a real interface now: one large record card, the input level inside it, the translated sentence below it, and an update you accept on that same screen. This release also closes the audio half of the v0.2 criterion with thirty minutes of continuous translation and no errors.

## Highlights

- The screen is redesigned around one action: a record card that pulses while you speak, with the microphone level inside it so you see it working before you talk.
- The translated sentence appears under the card as selectable text, next to the audio, so a name or a number can be copied and checked.
- **Install update** in the banner downloads, stages and replaces the binary. The page says plainly that losing the connection is the update happening, and the next `parlo app` runs the new version.
- Updates follow releases only. Nothing is published per commit, the app checks the latest tagged release, and the number it offers is a version with notes behind it.
- The `nightly` channel is gone, because a commit is not something a person should be asked to install.

## Measured

- Thirty minutes of continuous audio, Windows 11, 4 threads, cascade with Parakeet TDT 0.6B v3 int8, Argos and Piper, one 6 s Portuguese recording from a laptop Realtek microphone looped: 652 cycles, 1095 segments, mean 420.7 ms per segment, median 417 ms, p95 485 ms, first ten cycles 457.5 ms, last ten 399.4 ms, zero errors. Latency did not drift; the end of the run was 58 ms faster than the start.
- The translator behind the app is unchanged: first translated audio about 5.6 s after start on a live microphone, because the cascade needs a 2.5 s segment first.

## Install

```bash
cargo build --release -p parlo-cli
./target/release/parlo app
```

From this version on, `parlo update` and the button in the page both install the next release over the running copy.

## Known limitations

- The interface was not clicked through by the maintainer in a browser; its local endpoints were exercised directly, with the echo engine as well as a real 16 kHz WAV.
- Windows is the only platform validated end to end. macOS and Linux build in CI and their update path is written, not run.
- Portuguese and English only, machine translation quality, no installed desktop shell yet: the interface is served locally and opened in the browser.
- Thirty minutes of audio continuity passed; cold start, and a run reproduced by someone else, are still open for v0.2.
