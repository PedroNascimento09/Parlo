Parlo 0.2.8 adds eleven dictation languages, Command Mode, and a Whisper switch for quiet speech. Dictation now types at the cursor in the window you started from, and the first dictation of a session no longer waits for the model to load.

**Highlights**

- Eleven more languages: Polish, Swedish, Czech, Danish, Finnish, Greek, Romanian, Hungarian, Turkish, Ukrainian and Catalan, each with a translation pair with English and a text-to-speech voice.
- Command Mode (Ctrl+Alt+M): copy the selection in the captured window and change it with a spoken command (formal, casual, excited, uppercase, lowercase, title case, shorter, bullets), done locally with no model call.
- Whisper switch in the island: forces the microphone gain to 4x from the start of the recording, so the recogniser gets signal instead of silence at whisper level.
- Dictation types at the cursor in the window captured on the shortcut, while that window is still in front; the clipboard is the fallback when the window moved.
- The recogniser loads while you speak, so the first dictation of a session lands as fast as any later one.
- Releasing the key reuses the streamed sentence instead of transcribing the audio again: the text lands in 2 ms with Polish off, against 362 ms on the audio path, on a 2.8 s clip through the app's own server.
- Dictation trims the silence before the recogniser: about 375 ms instead of 570 ms from the end of the audio to the text on the reference machine.
- Updates check the downloaded archive against the release checksum before extracting it.
- Accented text survives the engine round trip, session tokens stay out of the engine log, and tickets now use cryptographic randomness.
- `parlo bench dictate` measures the dictation path end to end, and history corrections teach the vocabulary the next dictation uses.

**Measured**

- 636 Rust tests and 42 web tests pass with 0 failures (`cargo test --workspace`, the island harness, `check-languages.mjs`).
- Quiet speech into Parakeet (2 threads, local model, no cleanup): at whisper level (peak 0.040, RMS 0.0067) 4x gain reads 10 of 12 words (WER 0.25); without the gain the same clip transcribes as an empty string (WER 1.0). The automatic quiet detection only fires below peak 0.02, which a real whisper never reaches.
- 20 rendered clips at a 3 s window: a sentence that closes on silence costs 0 ms of decoding instead of 285.4 ms, with the same final text and the same WER.
- Polish is on screen in 2 ms and first provisional text arrives 150 ms sooner; the finished sentence lands 150 ms sooner, at the cost of one extra decode every three sentences.

**Install**

Windows: download `Parlo-Setup.exe` from the v0.2.8 release, or run `winget install Parlo`. Mac and Linux: download the matching `parlo-macos-aarch64.tar.gz` or `parlo-linux-x86_64.tar.gz` archive, extract it, and run `parlo app`. Both carry `SHA256SUMS.txt` and a build provenance record.

Parlo checks the latest release when the app starts and offers the update with these notes beside it. Nothing is installed without a click.

**Known limitations**

- The eleven new language packs download on demand from the Argos index and are marked experimental until measured here; nine of them dictate with Parakeet and Turkish and Catalan with Whisper.
- Insertion at the cursor only works while the captured window is still in front on stop; otherwise the text goes to the clipboard.
- Live replacement and Parlo's undo are still unavailable, because the previous text and the cursor cannot be verified yet.
- The package manifests in this tag carry the previous checksums for the archives; they are updated on main once the build finishes.

**Licences**

No new licences. The new language packs are Argos packs (Apache-2.0, OPUS-MT data), downloaded on demand like every other pack.
