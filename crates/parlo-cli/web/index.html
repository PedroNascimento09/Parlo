    The model that tidies your words

    A cloud or local model is optional. With none chosen, the rules alone clean the sentence and nothing leaves this machine.

    What leaves this machine

    Rules and the models on this machine send nothing. A cloud provider is reached only when you choose it, allow it here, and save a key: the sentence you dictated goes to that provider and nowhere else. There is no Parlo server in the middle.

    My voice

    A voice profile is how Parlo speaks a translation in your own voice instead of a neutral one. The profile, the sample and anything made from it stay in a folder on this computer, and you can revoke or delete them here at any time. Record a ten second sample here, hear it back, and export or delete the profile at any time; the sample and anything made from it stay in a folder on this computer. The engine that turns the sample into speech is not in this build yet, so the profile cannot speak a translation until it is.
