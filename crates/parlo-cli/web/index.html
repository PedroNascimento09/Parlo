                Licences and open source

                Parlo runs on this machine and every piece of it is open source. Each component keeps its own licence.

                • Parlo is MIT, moving to Apache-2.0. Read the licence
                • Parakeet TDT 0.6B v3 is CC-BY-4.0 and is downloaded, never shipped. Attribution: NVIDIA.
                • Whisper is MIT and is downloaded only when you pick it.
                • Argos Translate is MIT code with one licence per language package.
                • sherpa-onnx is Apache-2.0.
                • Piper is GPL-3.0-or-later, optional and installed separately. It is not part of any Parlo download, and Parlo works without it.

                The full list, with versions, notices and attributions, ships beside the program as THIRD_PARTY_NOTICES.md and sbom.cdx.json.
